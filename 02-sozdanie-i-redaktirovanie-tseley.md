# Создание и редактирование целей

Перед заполнением справочника целей стоит создать типы целей, например: «Стратегические цели», «Цели HR-отдела», «Маркетинговые цели». Если целей много, это упростит работу по заполнению карточек целей.

## Создание типов целей

Добавлять, изменять и удалять типы целей  могут только администраторы модуля. Перейдите в раздел «Каталог целей» и нажмите на шестеренку > «Типы целей».

![](./_images-02/image(1).png)

В результате откроется слайдер со списком всех типов целей. Создайте нужное количество типов целей и дайте им название. Нажмите «Сохранить», когда закончите работу с целями.

![](./_images-02/image(2).png)

В любой момент вы можете менять типы целей местами. Для этого зажмите нужную строку и передвиньте ее выше или ниже.

![](./_images-02/image(3).png)

Для удаления типа цели нажмите на бургер-меню слева от нее. Если в тип уже добавлены какие-то цели, бургер-меню не появится и удалить тип цели будет нельзя.

![](./_images-02/image(4).png)

После этого добавленные вами типы можно будет выбрать при [создании целей](#dobavlenie-tseley) и при добавлении их [в карточку целей](../../../../modules/ithive.goalsmanagement/user-guide/05-postanovka-i-soglasovanie-tseley/01-kartochka-tseley.md).

## Доступ к целям

При необходимости модуль позволяет массово настраивать доступ к целям. По умолчанию все цели создаются недоступными для сотрудников и видеть их может только администратор. Если цель недоступна, то пользователь не увидит такую цель в списке при заполнении карточки цели. Благодаря этому доступ к целям можно разграничивать например по отделам, чтобы при заполнении карточек руководители и их подчиненные видели только предназначенные для них цели.

Чтобы закрыть/открыть доступ ко всем целям перейдите в раздел «Каталог целей» и нажмите на шестеренку > «Доступы».

![](./_images-02/image(5).png)

Откроется слайдер с текущими настройками доступа. Чтобы открыть всем сотрудникам доступ к целям, для группы «Все посетители» установите тип доступа «Чтение». Сохраните изменения. 

Теперь все существующие и новые цели будут доступны всем сотрудникам при заполнении карточек. Менять права доступа в настройках каждой конкретной цели не потребуется.

![](./_images-02/image(6).png)

Чтобы закрыть доступ к целям для всех сотрудников, установите группе «Все посетители» тип доступа «Нет доступа». В результате сотрудники не будут видеть цели при заполнении своих карточек и доступ к каждой цели нужно будет настраивать отдельно при создании/редактировании данной цели. Подробнее об этом написано ниже в п.12.

![](./_images-02/image(7).png)

## Добавление целей

Добавлять, изменять и удалять цели могут только администраторы модуля. О том, как настроить права доступа для этой группы пользователей читайте [здесь](../../../../modules/ithive.goalsmanagement/user-guide/04-podgotovka-i-zapusk-protsessa/01-roli-polzovateley-i-prava-dostupa.md).

Перейдите в раздел «Каталог целей» и нажмите на кнопку «Добавить цель».

[![](./_images-02/image202.png)](https://portal.wehive.digital/~9Wt0s)

В открывшемся слайдере вы увидите следующие параметры:

1. **Активность цели.** Эта опция влияет на добавление цели в карточку целей. Если галочка активна, сотрудники будут видеть данную цель в выпадающем списке и смогут добавить ее в свою карточку.

[![](./_images-02/image139.png)](https://portal.wehive.digital/~cY5s6)

[![](./_images-02/image142.png)](https://portal.wehive.digital/~MZFN7)

Если галочка убрана, цель нельзя будет добавить в карточку. Доступ к цели будет только у администратора модуля и сотрудника внутреннего контроля в разделе «Каталог целей».

2. **Название цели.** Наименование цели. Данное поля обязательно для заполнения. Примеры формулировок для целей вы можете посмотреть [здесь](../../../../modules/ithive.goalsmanagement/user-guide/03-o-produkte/02-ispolzovanie-modulya.md).

3. **Тип цели.** Категория цели, например «Стратегические цели» или «Маркетинговые цели». О добавлении типов целей написано выше.

[![](./_images-02/image168.png)](https://portal.wehive.digital/~k0NnK)

4. **Минимальный вес цели.** В этом поле указывается минимальный вес одной цели, который пользователь может указать в карточке цели. Вес — это приоритетность цели, чем больше вес, тем приоритетнее цель. По умолчанию минимальный вес цели — 10. Изменить это значение можно в [настройках модуля](../../../../modules/ithive.goalsmanagement/user-guide/07-administrirovanie-modulya/01-nastroyki-modulya-upravlenie-tselyami-kaskad.md).

[![](./_images-02/image157.png)](https://portal.wehive.digital/~AA5Sw)

Пользователи указывают вес, когда заполняют свои карточки целей — это обязательный параметр. Суммарный вес всех целей в одной карточке должен быть равен 100. Минимальный вес цели нужен, чтобы более объективно указывать приоритетность целей.

[![](./_images-02/image178.png)](https://portal.wehive.digital/~qT0Bu)

<!-- markdownlint-disable-next-line MD033 -->
<span class="img-caption">Указание веса целей в карточке целей</span>

Например, если вес первой цели — 1, а второй — 99, такое соотношение выглядит нереалистично. Получается, что сотрудник будет уделять работе с первой целю 1% своего времени — в этом мало смысла.

Минимальный вес цели задается, чтобы таких ситуаций не возникало. Например, сотрудник не сможет указать вес цели меньше 10. Тогда расстановка приоритетов будет более логичной.

5. **Шаг изменения веса цели.** Это поле позволяет сделать более объективной настройку веса цели. Шаг — это то, на сколько единиц можно изменять вес цели. Например, исходный вес цели 10, а шаг равен 1. Значит, сотрудник может указать вес 11, 12, 13 и так далее. Если шаг равен 5, то сотрудник может указать вес 15, 20, 25 и так далее.

[![](./_images-02/image50.png)](https://portal.wehive.digital/~CvKVl)

6. **Максимальный % выполнения цели.** В этом поле указывается максимальный процент выполнения цели, которого может достичь сотрудник в своей карточке оценки. К примеру, если при постановке целей важно учитывать перевыполнение плана, то в поле можно указать 120%.

[![](./_images-02/image218.png)](https://portal.wehive.digital/~VbYlv)

[![](./_images-02/image88.png)](https://portal.wehive.digital/~wxvng)

<!-- markdownlint-disable-next-line MD033 -->
<span class="img-caption">Индикатор прогресса в карточке оценки</span>

7. **Шаг изменения % выполнения цели.** Это поле позволяет более объективно указывать прогресс по целям. Шаг — это то, на сколько единиц можно изменять прогресс. Например, исходный прогресс 0, а шаг равен 1. Значит, сотрудник может указать прогресс 1%, 2%, 3% и так далее. Если шаг равен 5, то сотрудник может указать прогресс 5%, 10%, 15% и так далее.

[![](./_images-02/image132.png)](https://portal.wehive.digital/~2Sd20)

[![](./_images-02/image116.png)](https://portal.wehive.digital/~CJw1c)

8. **Текст подсказки при редактировании веса цели.** В это поле администратор может добавить пояснение для сотрудников о том, как правильно указывать вес цели.

[![](./_images-02/image226.png)](https://portal.wehive.digital/~V25jZ)

При заполнении карточек целей сотрудники увидят данное пояснение как всплывающую подсказку:

[![](./_images-02/image36.png)](https://portal.wehive.digital/~rtVlh)

9. **Текст подсказки при редактировании % выполнения цели.** В это поле администратор может добавить пояснение для сотрудников о том, как правильно фиксировать прогресс по цели.

[![](./_images-02/image12.png)](https://portal.wehive.digital/~9KQl2)

При заполнении карточек оценок сотрудники увидят данное пояснение как всплывающую подсказку:

[![](./_images-02/image151.png)](https://portal.wehive.digital/~tb0Za)

10.  **Возможности каскадирования.** Опция позволяет включить или отключить автоматическое каскадирование цели подчиненным. Если опция отключена руководитель по-прежнему сможет вручную добавлять цели в карточки подчиненных.

[![](./_images-02/image31.png)](https://portal.wehive.digital/~fNvHC)

[![](./_images-02/image79.png)](https://portal.wehive.digital/~Ono9t)

Если опция каскадирования включена, первыми свои карточки целей должны заполнить руководители — пока их цели не утверждены, подчиненные не смогут приступить к заполнению собственных карточек.

11. **Фоновый цвет.** Настройка позволяет задать фоновый цвет для каждой цели. Цвет отобразится в карточках целей и оценок. Это удобно, чтобы визуально отделять разные цели друг от друга.

[![](./_images-02/image28.png)](https://portal.wehive.digital/~1nzRt)

Для удобства вы можете воспользоваться готовой палитрой цветов по [этой ссылке](https://gradients.app/ru/newcolorpalette/d2e7d1-efffe6-dcdcdc-e2ebee-e8faff-e2eafc-f3dee2-f5edf0-e6ddd5-f5e6da?share=link). Палитра состоит из 10 пастельных цветов, HEX-код каждого цвета можно скопировать и указать в настройках цели. С помощью этого сервиса вы также можете подобрать свои цвета для целей.

В карточках целей и оценок предложенные цвета выглядят так:

12. **Настройка прав.** Здесь настраиваются права доступа к цели — эту настройку нужно обязательно выполнить, чтобы пользователи могли добавлять цель в свои карточки.

[![](./_images-02/image184.png)](https://portal.wehive.digital/~OXft3)

По умолчанию цель скрыта ото всех пользователей, кроме администраторов модуля и сотрудников внутреннего контроля. Чтобы другие сотрудники видели цель и могли добавить ее себе в карточку, выберите группу пользователей и укажите для нее права «Чтение».

[![](./_images-02/image147.png)](https://portal.wehive.digital/~qzoTy)

Кроме чтения в списке прав есть и другие виды доступа стандартные для Битрикс24. Сейчас они не используются в модуле «УЦ. Каскад», но их внедрение запланировано на будущее. В результате каталогом целей смогут управлять несколько человек, каждый из которых будет иметь доступ к конкретной группе целей.

## Редактирование и удаление целей

Чтобы отредактировать цель, в общем списке целей кликните на бургер-меню (≡) рядом с нужным названием и выберите «Изменить». Внесите изменения на слайдере и сохраните изменения.

[![](./_images-02/image146.png)](https://portal.wehive.digital/~WlEdn)

[![](./_images-02/image233.png)](https://portal.wehive.digital/~lamDe)

**Важно!** Если цель используется в запущенном процессе, отредактировать ее тип и название уже нельзя.

Если отключить активность цели и закрыть к ней доступ, те сотрудники которые уже добавили цель в свою карточку будут по-прежнему ее видеть.

[![](./_images-02/image130.png)](https://portal.wehive.digital/~RhNyl)

Для удаления цели выберите соответствующий пункт в выпадающем меню.

[![](./_images-02/image110.png)](https://portal.wehive.digital/~fv2HB)

Если цель уже используется в запущенном процессе, она исчезнет из карточек целей, карточек оценок и из сводного отчета. По этой причине удалять используемые цели не рекомендуется.
