# Типы программ развития в Корпоративном университете

Для обучения в Корпоративном университете используются программы развития (ИПР). Такие программы представляют собой список компетенций, которые должен освоить сотрудник. У каждой компетенции свой набор развивающих действий, которые нужно выполнить для получения этой компетенции.

![](./_images-02/image466.png)

В модуле предусмотрено два типа программ:

- Программа развития

- Программа адаптации

## Программа развития

Программа развития — это набор из компетенций (soft и hard skills, корпоративные компетенции), которые сотрудник должен развить с нуля или улучшить. Каждая программа имеет руководителя, четкие сроки завершения, список развивающих действий.

## Для чего используются программы развития

В Корпоративном университете программы развития могут использоваться для следующих целей:

- Развитие сотрудника для перехода на вышестоящую/смежную позицию;

- Развитие сотрудника в рамках его текущей позиции;

- Изучение отдельных компетенций по желанию сотрудника или для включения сотрудника в кадровый резерв;

- Выполнение отдельных развивающих действий в целях саморазвития (прохождение курсов, чтение книг, посещение мероприятий и т.п).

## Сроки программ развития

По умолчанию программы развития рассчитаны на длительный срок прохождения. Срок программы может быть установлен от 6 месяцев до 2 лет. Однако эти сроки можно изменить в [административной части](../../../../modules/ithive.ipr/user-guide/09-administrativnaya-chast-modulya/06-nastroyka-srokov-programm.md) портала.

![](./_images-02/image718.png)

## Варианты запуска программ развития

В зависимости от целей обучения в модуле предусмотрено три варианта запуска программ развития:

1. Запуск по шаблону

2. Запуск на основании карьерной траектории/текущей позиции

3. Свободный выбор компетенций

Подробнее о запуске программ развития написано в [отдельной статье](../../../../modules/ithive.ipr/user-guide/06-razvitie-sotrudnikov/03-odinochnyy-zapusk-programm-razvitiya.md).

## Программа адаптации

Программа адаптации — это та же программа развития, но нацеленная на онбординг новых сотрудников.

Единственное отличие программ адаптации от обычных программ развития — это сроки. По умолчанию программы адаптации рассчитаны на небольшой срок прохождения. Срок программы может быть установлен от 1 до 3 месяцев. Однако эти сроки можно изменить в [административной части](../../../../modules/ithive.ipr/user-guide/09-administrativnaya-chast-modulya/06-nastroyka-srokov-programm.md) портала.

![](./_images-02/image752.png)

В модуле предусмотрен единственный вариант запуска программы адаптации — запуск по шаблону.

## Как включить/отключить программы адаптации

По умолчанию в настройках модуля включена опция «Использовать программы адаптации». Это позволяет создавать шаблоны программ адаптации и запускать по ним развитие.

![](./_images-02/image23.png)

При необходимости опцию можно отключить. В этом случае в Корпоративном университете нельзя будет создавать шаблоны программ адаптации и запускать по ним развитие.

## Автоматический запуск программ адаптации

При создании любых шаблонов развития можно включить опцию автоматического запуска, что особенно актуально для программ адаптации. Благодаря этому при добавлении новых сотрудников на портал для них будет автоматически запускаться программа адаптации по преднастроенному шаблону.

![](./_images-02/image663.png)

Для разных подразделений можно создать свои шаблоны программ адаптации — это поможет создать централизованный и индивидуальный подход к адаптации новых сотрудников в компании.
