# Одиночный запуск программ развития

Корпоративный университет позволяет запускать программы развития (ИПР) для сотрудников как индивидуально, так и массово. Индивидуальный (одиночный) запуск выполняется через профиль конкретного пользователя. Массовый запуск выполняется через раздел Корпоративного университета «Сотрудники». 

В этой статье рассмотрены все варианты индивидуального запуска программ развития. О массовом запуске программ развития написано [здесь](../../../../modules/ithive.ipr/user-guide/06-razvitie-sotrudnikov/04-massovyy-zapusk-programm-razvitiya.md).

## Права на одиночный запуск программ развития

В Корпоративном университете есть 4 роли пользователей, которым доступен одиночный запуск программ развития:

- **Администратор.** Может запускать программы развития для любых пользователей корпоративного портала.

- **Группа HR-отдела.** Может запускать программы развития для любых пользователей корпоративного портала. [Подробнее](../../../../modules/ithive.ipr/user-guide/09-administrativnaya-chast-modulya/03-nastroyki-modulya-korporativnyy-universitet.md)

- **Руководитель согласно оргструктуре.** Может запускать программы развития только для своих прямых подчиненных.

- **Обычный пользователь.** Может запускать программы развития только для себя. Для этого в настройках модуля должны быть включены соответствующие опции. [Подробнее (п. 7-8)](../../../../modules/ithive.ipr/user-guide/09-administrativnaya-chast-modulya/03-nastroyki-modulya-korporativnyy-universitet.md)

## Варианты запуска и их особенности

Всего в модуле предусмотрено 3 варианта запуска программ развития.

1. Запуск по шаблону программы развития/адаптации.

2. Запуск на основе карьерной траектории/текущей позиции.

3. Запуск со свободным выбором компетенций.

Все эти варианты доступны при одиночном запуске, т.е. при запуске программы развития для одного конкретного пользователя. Рассмотрим особенности данных вариантов запуска.

### Запуск по шаблону программы развития/адаптации

В этом случае при запуске программы развития нужно выбрать соответствующий шаблон. Шаблон — это заранее подготовленный набор компетенций для освоения. При создании шаблона HR-специалист самостоятельно решает, какие компетенции в него включить. Запущенная программа развития будет содержать указанные компетенции.

Например, в шаблон «Онбординг нового сотрудника» могут входить такие компетенции как «Знание продуктовой линейки», «Знание основной информации о компании» и тому подобное. О нюансах выбора компетенций для развития написано ниже.

Шаблоны можно создавать как для обычных программ развития, так и для программ адаптации. Опции запуска развития по шаблону появляются в профиле сотрудника только если создан хотя бы один шаблон развития/адаптации. Данные опции выглядят следующим образом:

![](./_images-03/image633.png)

Чтобы создавать шаблоны программ адаптации и запускать по ним развитие, в настройках модуля должна быть включена опция «Использовать программы адаптации». Если опция отключена, то возможность запуска программ адаптации будет скрыта из профиля сотрудника.

### Запуск на основе карьерной траектории/текущей позиции

Этот вариант означает развитие в какую-либо позицию из раздела «Карьерные траектории», например, в позицию Технического директора или Руководителя проектов.

Такая программа развития будет содержать компетенции из профиля позиции, на основе которой запущено развитие. Например, если развитие запущено на в позицию «Технический директор», то для развития будут автоматически выбраны компетенции, которые входят в эту позицию. О нюансах выбора компетенций для развития написано ниже.

В этом случае может быть два пути запуска:

- **На основе карьерное траектории.** Означает развитие в вышестоящую или смежную позицию. Для запуска такой программы сотрудник должен быть привязан к позиции, для которой указаны горизонтальные и/или вертикальные пути развития.

Например, для позиции «Тестировщик Junior» может быть указан вертикальный путь развития в вышестоящую позицию «Тестировщик Middle». Если в данный момент сотрудник привязан к позиции «Тестировщик Junior», то в его профиле появится опция для развития по вертикальной карьерной траектории — в позицию «Тестировщик Middle».

### Запуск со свободным выбором компетенций

В этом случае компетенции, входящие в программу развития, не зависят от шаблонов и позиций. Прямо при запуске программы HR-специалист или сам сотрудник выбирает те компетенции, которые нужно развить. Такой вариант запуска используется для целенаправленной отработки отдельных компетенций. Например, когда сотрудник выражает желание освоить новые компетенции, а также когда есть необходимость в подготовке кадрового резерва.

## Запуск программ развития

Рассмотрим особенности запуска каждого из трех вариантов развития. Запуск развития выполняется из профиля конкретного сотрудника. Для этого зайдите в профиль и выберите нужный вариант запуска. В результате откроется слайдер запуска развития.

![](./_images-03/image166.png)

### Программы развития/адаптации

При выборе такого варианта запуска на слайдере будут доступны следующие поля:

1. **Выберите шаблон**. Опция появляется только если при запуске была выбрана опция «Программы развития»/«Программы адаптации». В поле нужно выбрать один из созданных шаблонов программы развития/адаптации. Компетенции из шаблона будут автоматически выбраны в блоке справа — их можно оставить без изменений или отредактировать.

![](./_images-03/image687.png)

2. **Руководитель.** Поле для выбора руководителя, который будет следить за выполнением программы развития. От руководителя зависят оценки по компетенциям и завершение развития. Поле обязательно для заполнения.

В поле автоматически подставляется руководитель сотрудника согласно оргструктуре компании, но его можно изменить на любого другого сотрудника. Сотрудника нельзя выбрать руководителем своей же карточки.

3. **Отправить на согласование руководителю**. Если галочка включена, то после запуска карточка будет находиться в статусе«Черновик» пока ее не одобрит указанный руководитель. Если опция отключена, то при запуске программа сразу попадет сотруднику в работу.

![](./_images-03/image537.png)

4. **Наблюдатели**. В данном поле можно указать пользователей, которым карточка развития будет доступна для просмотра. Эти пользователи будут видеть карточку в разделе «Мониторинг развития». Также во всех разделах аналитики по курсам наблюдатели видят результаты тестирования сотрудника по тем курсам, которые добавлены в данную карточку развития.

5. **Срок.** Длительность выполнения программы развития. В это поле автоматически проставляется срок из выбранного шаблона программы, однако его можно изменить. По умолчанию для программы развития срок может быть от 6 месяцев до 2 лет, для программы адаптации — от 1 до 3 месяцев. При необходимости изменить доступные сроки программы развития можно в [административной части портала](../../../../modules/ithive.ipr/user-guide/09-administrativnaya-chast-modulya/06-nastroyka-srokov-programm.md).

![](./_images-03/image706.png)

6. **Указать/Скрыть целевую должность.** Поле будет автоматически заполнено если в выбранном шаблоне развития указана целевая должность. Если должность указана, то у руководителя карточки будет возможность автоматически установить эту должность в профиле сотрудника после завершения развития. Если не этого делать нужно, данное поле можно не заполнять.

![](./_images-03/image781.png)

7. **Указать/Скрыть целевую позицию**. Поле будет автоматически заполнено если в выбранном шаблоне развития указана целевая позиция. Если позиция указана, то у руководителя карточки будет возможность автоматически установить эту позицию в профиле сотрудника после завершения развития. Если не этого делать нужно, данное поле можно не заполнять.

![](./_images-03/image769.png)

8. **Указать/Скрыть следующую программу.** Опция нужна для автоматизации запуска программ развития и позволяет сотруднику после завершения одной программы сразу приступать к выполнению следующей. Данная опция может быть использована, например, для выстраивания аналога карьерной траектории. Если не нужно чтобы сотрудник приступал к выполнению следующей программы развития, данное поле можно не заполнять.

![](./_images-03/image666.png)

9. **Компетенции.** В этом блоке происходит выбор компетенций для развития. При указании шаблона компетенции из него автоматически отмечаются галочками, т.е. становятся выбраны для развития. Однако на выбор компетенций для развития также влияет то, на каком уровне сотрудник владеет этими компетенциями в данный момент.

![](./_images-03/image520.png)

Уровни владения компетенциями обозначается тремя иконками:

1. **Серая галочка** (![](./_images-03/image685.png)) — сотрудник не владеет компетенцией. Такая компетенция будет выбрана для освоения и ее нельзя будет убрать, галочка будет заблокирована.

2. **Синяя галочка** (![](./_images-03/image253.png)) — сотрудник владеет данной компетенцией на достаточном уровне для работы. Такая компетенция будет выбрана для освоения, но ее можно будет убрать, сняв галочку.

3. **Академическая шапочка** (![](./_images-03/image613.png)) — сотрудник является экспертом по данной компетенции и может выступать в роли наставника в обучении. Такая компетенция не будет выбрана для освоения, но ее можно будет добавить.

![](./_images-03/image32.png)

Помимо автоматически добавленных компетенций для развития можно выбрать и любые другие существующие компетенции.

Для каждой компетенции можно указать свой срок развития, а также набор развивающих действий. Подробнее об этом написано ниже.

## Сроки развития компетенций и развивающие действия

При любом варианте запуска для каждой компетенции доступен выбор даты дедлайна. По умолчанию указан дедлайн самого позднего развивающего действия по данной компетенции. Если указать крайний срок выполнения вручную, то эта дата будет автоматически выставлена для всех развивающих действий по данной компетенции.

В дальнейшем сроки выполнения развивающих действий можно будет настроить вручную в самой карточке развития. Для этого у пользователя должны быть соответствующие права доступа.

[Редактирование карточки развития](../../../../modules/ithive.ipr/user-guide/06-razvitie-sotrudnikov/07-redaktirovanie-kartochki-razvitiya.md)

![](./_images-03/image11.png)

По клику на кнопку «Действий N/M» откроется слайдер выбора развивающих действий для данной компетенции. Выбранные действия будут включены в программу развития. M — это количество обязательных и рекомендуемых развивающих действий указанных для данной компетенции. N — это количество действий из числа M, которые выбраны для прохождения. По умолчанию для прохождения выбраны только обязательные действия.

![](./_images-03/image17.png)

На слайдере выбора развивающих действий вы можете отредактировать цель развития, выбрать/убрать развивающие действия из программы и указать дедлайны для развивающих действий.

![](./_images-03/image353.png)

Ниже на слайдере расположена кнопка «Добавить» по клику на которую в программу развития можно добавить любые другие виды развивающих действий.

![](./_images-03/image317.png)

Обратите внимание, что для добавления доступны только уже созданные действия. Данный интерфейс не предусматривает создание новых развивающих действий.

![](./_images-03/image779.png)

После заполнения всех настроек нажмите на кнопку «Запустить».

![](./_images-03/image109.png)

Когда программа будет запущена в профиле сотрудника появится карточка развития. Программа готова к прохождению.

![](./_images-03/image121.png)

![](./_images-03/image509.png)

## Лимит на количество программ в работе

В Корпоративном университете есть ограничение на количество программ одновременно запущенных для сотрудника. По умолчанию в работе у сотрудника может быть не более 2-х программ. В [настройках модуля](../../../../modules/ithive.ipr/user-guide/09-administrativnaya-chast-modulya/03-nastroyki-modulya-korporativnyy-universitet.md) этот лимит можно увеличить до пяти.

Если лимит превышен, кнопка запуска программы будет заблокирована.

![](./_images-03/image747.png)
