# База знаний - История версий

**Модуль:** [[Module - База знаний]]

## Описание

Перечень всех выпущенных обновлений по модулю «База знаний».

## Ключевые функции

> Список основных изменений по версиям модуля.

- Версионность статей
- Корзина для удаления статей и разделов
- CoPilot для генерации и обработки текста
- Публичные ссылки на статьи
- Статистика просмотров
- Стартовая страница
- Комментирование статей
- Мобильное приложение
- Многосайтовость
- Поддержка PostgreSQL

## Предусловия

Модуль «База знаний» должен быть установлен на портале.

## Шаги

1. Перейти в настройки модуля «База знаний»
2. Ознакомиться с историей версий для понимания доступного функционала

## Ожидаемый результат

Полное понимание изменений и нового функционала, добавленного в каждой версии модуля.

## Граничные случаи

> При обновлении модуля рекомендуется ознакомляться с историей версий для выявления критических изменений и новых возможностей.
