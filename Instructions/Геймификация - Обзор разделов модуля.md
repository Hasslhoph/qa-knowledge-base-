# Геймификация - Обзор разделов модуля

**Модуль:** [[Module - Геймификация]]

## Описание

Модуль «Геймификация» (пункт меню «Бонусная программа») состоит из шести разделов: «Лента событий», «Операции», «Рейтинги», «Доска почета», «Магазин бонусов», «О программе».

## Ключевые функции

### Лента событий
- Функционально похожа на стандартную ленту Битрикс24, но отражает события, связанные с модулем «Геймификация»
- Отображаемые события: благодарности, перечисление баллов «Спасибо», начисление баллов за призовые места в рейтингах, дни рождения, годовщины работы
- Всем пользователям доступна кнопка «Спасибо» для перечисления баллов коллегам

### Операции
- **Для обычных пользователей:** все транзакции по внутреннему счёту (начисления баллов, списания при покупках, передача «Спасибо»)
- Фильтры для быстрого поиска нужных типов операций
- **Для администраторов:** видны операции всех пользователей, доступна кнопка «Добавить» для ручного начисления/списания баллов
- Операции (транзакции) нельзя редактировать или удалять — баланс меняется только через новые операции

### Рейтинги
- Семь основных рейтингов: Общий, Эффективный исполнитель задач, Эффективный постановщик задач, Активное развитие, Лидер продаж, Эффективный пользователь календаря, Главный по новостям
- В каждом рейтинге выводятся позиции участников (до 10 по умолчанию, настраивается)
- Три призовых места: золото, серебро, бронза
- Индикатор участия пользователя в каждом рейтинге
- Автоматическое обновление каждые сутки
- Блок «Призеры предыдущих месяцев»

### Доска почета
- Отображает призеров каждого рейтинга за прошедший месяц
- Автоматическое обновление при подведении итогов
- Кнопка «Спасибо» для каждого сотрудника

### Магазин бонусов
- Позиции, которые сотрудники могут купить за накопленную игровую валюту
- Каждый сотрудник видит свой текущий уровень (ранг) и баланс баллов

### О программе
- Справочный раздел с ответами на частые вопросы
- Материалы доступны всем пользователям независимо от уровня доступа
- Описание можно редактировать через HTML (код фразы: ABOUT_GAMIFICATION_TEXT, файл: /bitrix/modules/ithive.gamification/lang/ru/public/index.php)

## Предусловия

- Модуль установлен и настроен
- Пользователь имеет доступ к публичной части модуля

## Шаги

1. Перейдите в раздел «Бонусная программа» в публичной части портала
2. Изучите каждый из шести разделов

## Ожидаемый результат

Пользователь понимает структуру модуля и назначение каждого раздела.

## Граничные случаи

- Обычные пользователи видят только свои операции в разделе «Операции»
- Администраторы видят операции всех пользователей и могут начислять баллы вручную
- В рейтингах по умолчанию отображается до 10 участников (настраивается)
- Призовых мест стандартно три: золото, серебро, бронза
- Для редактирования описания раздела «О программе» требуются знания HTML-верстки
