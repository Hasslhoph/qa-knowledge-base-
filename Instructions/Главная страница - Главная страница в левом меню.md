# Главная страница - Главная страница в левом меню

**Модуль:** [[Module - Главная страница]]

## Описание

Инструкция по скрытию Главной страницы и её разделов из левого меню на время наполнения контентом, а также рекомендации по установке Главной в качестве стартовой страницы портала для сотрудников.

## Ключевые функции

- Скрытие из левого меню разделов: Новости компании, Новости СМИ, Сервисы и заявки, Лидеры продаж, Кадровые изменения
- Скрытие пунктов «Главная» и «О компании» из левого меню
- Установка Главной стартовой страницей портала через настройку левого меню
- Использование Главного инструмента «HR-Portal» для приоритетного расположения модулей Улья в левом меню
- Информирование сотрудников через [[Module - Интерактивные подсказки]]

## Предусловия

- Права администратора портала
- Доступ к административной части (`/bitrix/admin/`)
- Путь к настройкам модуля: `/bitrix/admin/settings.php?lang=ru&mid=ithive.homepage`

## Шаги

### Как скрыть Главную страницу из левого меню

1. Перейдите в административную часть портала: `/bitrix/admin/`
2. Нажмите «Настройки» > «Улей: Главная страница» (или перейдите по ссылке `/bitrix/admin/settings.php?lang=ru&mid=ithive.homepage`)
3. **Центральный блок:** перейдите во вкладку «Компоненты», выберите вкладку нужного сайта, снимите галочки во всех пунктах колонки «Вывести в левом меню». Будут скрыты: Новости компании (`/news/`), Новости СМИ (`/news2/`), Сервисы и заявки (`/proposals/`), Лидеры продаж (`/leader_sales/`), Кадровые изменения (`/company/events.php`)
4. **Главная и О компании:** перейдите во вкладку «Источники данных», откройте вкладку второго сайта, снимите галочки «Вывести в левом меню пункт "Главная"» и «Вывести в левом меню пункт "О компании"»

### Как сделать Главную стартовой страницей портала

1. **Установить своё меню для всех:** администратор перемещает пункт «Главная» на первое место в своём левом меню, затем устанавливает своё меню для всех (или только для новых) сотрудников через настройки портала.
2. **Использовать Главный инструмент «HR-Portal»:** при выборе этого инструмента все решения Улья выстраиваются в верхней части левого меню; Главная автоматически встаёт на первое место. HR-Portal особенно удобен для компаний, использующих несколько HRM-решений Улья.
3. **Порекомендовать сотрудникам:** рассказать о полезных функциях Главной и попросить вручную переместить её на первое место в меню. Использовать [[Module - Интерактивные подсказки]] для всплывающих подсказок прямо на Главной.

## Ожидаемый результат

- Временное скрытие разделов из левого меню при сохранении доступа по прямым ссылкам
- Главная страница становится стартовой страницей портала для выбранных категорий сотрудников

## Граничные случаи

- Разделы пропадают только из левого меню, но остаются доступными по прямым ссылкам (ответственные пользователи могут наполнять контент)
- Главная и «О компании» не появляются автоматически вверху левого меню при установке — они добавляются вниз списка, чтобы не нарушать пользовательские настройки
- При включении любого Главного инструмента меняется порядок ВСЕХ пунктов левого меню — пользовательский порядок заменяется на стандартный
- Если на портале нет других решений Улья, инструмент «HR-Portal» всё равно можно применить — пункты «Главная» и «О компании» будут перемещены в самый верх
