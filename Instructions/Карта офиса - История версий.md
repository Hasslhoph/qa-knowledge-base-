# Карта офиса - История версий

**Модуль:** [[Module - Карта офиса + Бронирование]]

## Описание

Перечень всех выпущенных обновлений по модулю «Карта офиса + бронирование рабочих мест».

## Ключевые функции

### 2 квартал 2026
- **Версия 8.0.0** — реализация REST API
- **Версия 7.2.5** — исправлено отображение даты в слайдере бронирования в Safari
- **Версия 7.2.4** — оптимизация кода, перенос тихой установки
- **Версия 7.2.3** — внешний код иконок равен их ID
- **Версия 7.2.2** — добавлен компонент виджета «Мои бронирования» на главную страницу
- **Версия 7.2.1** — правка подключения air стилей в фильтре «Кто в офисе»
- **Версия 7.2.0** — добавлена опция отключения функционала бронирования мест
- **Версия 7.1.1** — исправлена отмена брони в мобильном приложении на старых ядрах
- **Версия 7.1.0** — параллельное бронирование для разных типов рабочих мест

### 1 квартал 2026
- **Версия 7.0.4** — закрашивание полностью занятых мест в календаре при частичном бронировании
- **Версия 7.0.3** — запрет бронирования двух мест одновременно (с ПК и без ПК)
- **Версия 7.0.2** — оптимизация кода
- **Версия 7.0.1** — исправление меню в мобильном приложении после обновления ядра

### 2023-2025
- **Версия 7.0.0** — настройка ограничения видимости публичного функционала для групп, разделение по сайтам
- **Версия 6.1.1** — исправление часовых поясов
- **Версия 6.1.0** — поддержка часового пояса на уровне кабинета
- **Версия 6.0.0** — поддержка английского языка
- **Версия 5.7.0** — работа модуля в режиме многодепартаментности
- **Версия 5.6.0** — обновлён мобильный интерфейс бронирований
- **Версия 5.5.0** — слайдер с логами бронирований для администраторов с экспортом
- **Версия 5.4.0** — пересекающиеся бронирования разных типов мест, управление подтверждением
- **Версия 5.3.0** — управление иконками рабочих мест из настроек модуля
- **Версия 5.2.0** — бронирование одних и тех же мест несколько раз в день
- **Версия 5.1.0** — зависимость от модуля Pull
- **Версия 5.0.0** — «тихая» установка модуля
- **Версия 4.1.0** — масштаб карты «Вписать», масштабирование иконок пользователей
- **Версия 4.0.0** — импорт SVG и автоматическое наполнение рабочих мест, уровни город/офис/кабинет
- **Версия 3.0.0** — функционал в мобильном приложении
- **Версия 2.5.0** — управление Легендой через HL-блок
- **Версия 2.4.0** — раздел «Кто в офисе», вывод закреплённых мест
- **Версия 2.3.0** — подтверждение бронирований, отмена с выбором типа и причины
- **Версия 2.2.0** — массовое редактирование прав на рабочие места
- **Версия 2.1.0** — повторные бронирования
- **Версия 2.0.0** — новые опции модуля
