# Корпоративный университет - Массовый запуск программ развития

**Модуль:** [[Module - Корпоративный университет]]

## Описание

Массовый запуск программ развития (ИПР) выполняется через раздел «Сотрудники». Для выбранных сотрудников запускается одна и та же программа.

## Ключевые функции

### Права на массовый запуск
- Администратор
- Группа HR-отдела
- Обычные сотрудники и структурные руководители имеют права только на одиночный запуск

### Варианты массового запуска
1. **По шаблону программы развития/адаптации** — доступен
2. **Свободный выбор компетенций** — доступен
3. **На основе карьерной траектории/текущей позиции** — НЕ доступен при массовом запуске

### Шаг 1: Запуск из раздела «Сотрудники»
1. Отметьте нужных сотрудников галочками
2. Выберите действие «Запустить программу»
3. Выберите вариант запуска

#### Поля слайдера (для шаблона)
- **Шаблон** — выбор шаблона программы развития или адаптации
- **Как определять руководителя** — вычислить по оргструктуре или выбрать одного на всех
- **Отправить на согласование руководителю**
- **Наблюдатели**
- **Срок** — автоматически из шаблона (можно изменить)
- **Целевая должность, Целевая позиция, Следующая программа**
- **Компетенции** — автоматически из шаблона (нельзя удалить)

#### Поля слайдера (для свободного выбора)
- Аналогично, но без шаблона, целевой должности и целевой позиции
- Компетенции не выбраны изначально — без выбора запуск невозможен

### Шаг 2: Настройка и проверка данных перед запуском
На втором шаге доступны фильтры и таблица для финальной настройки:

**Фильтры:**
- **Исходное выбранное количество сотрудников** — полный список
- **Сотрудники с имеющимися компетенциями** — только те, кто уже владеет какими-либо развиваемыми компетенциями
- **Будет запущено** — успешно запускаемые карточки
- **Не будет запущено** — карточки с блокирующими факторами

**Причины блокировки запуска:**
- У сотрудника уже есть программа по такому же шаблону
- Превышен лимит программ (по умолчанию 2, до 5 в настройках)
- Сотрудник уволен
- Вручную отменён запуск (снята галочка)

**Колонки таблицы:**
- Сотрудник — чекбокс для включения/исключения
- Руководитель — можно изменить индивидуально
- Имеющиеся компетенции — освоенные компетенции с чекбоксами
- Итог — предварительный статус
- Комментарий — причины блокировки

### Развивающие действия
- Для каждой компетенции — выбор даты дедлайна
- Кнопка «Действий N/M» — выбор развивающих действий
- Кнопка «Добавить» — добавить другие виды действий (только уже созданные)

## Предусловия

- Права администратора или группы HR-отдела
- Созданные шаблоны программ (для запуска по шаблону)

## Граничные случаи

- При массовом запуске невозможно выбрать для каждого сотрудника свою индивидуальную программу
- На втором шаге можно исключить отдельных сотрудников, изменить руководителей и убрать уже освоенные компетенции
- В отличие от одиночного запуска, уровни владения компетенциями не выводятся на первом шаге
