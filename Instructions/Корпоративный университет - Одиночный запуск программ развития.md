# Корпоративный университет - Одиночный запуск программ развития

**Модуль:** [[Module - Корпоративный университет]]

## Описание

Индивидуальный запуск программ развития (ИПР) выполняется через профиль конкретного пользователя.

## Ключевые функции

### Права на одиночный запуск
- **Администратор** — для любых пользователей
- **Группа HR-отдела** — для любых пользователей
- **Руководитель согласно оргструктуре** — только для прямых подчинённых
- **Обычный пользователь** — только для себя (при включённых соответствующих опциях в настройках модуля)

### Три варианта запуска
1. **По шаблону программы развития/адаптации** — выбор заранее подготовленного набора компетенций
2. **На основе карьерной траектории или текущей позиции** — компетенции из профиля позиции
3. **Свободный выбор компетенций** — ручной выбор компетенций для развития

### Поля слайдера запуска
- **Шаблон** — доступен только при запуске по шаблону; компетенции из шаблона автоматически выбираются
- **Руководитель** — обязательное поле; автоматически подставляется из оргструктуры (можно изменить); нельзя выбрать владельца карточки
- **Отправить на согласование руководителю** — если включено, карточка запускается в статусе «Черновик» до одобрения
- **Наблюдатели** — пользователи, которым карточка доступна для просмотра и аналитики
- **Срок** — для программы развития от 6 мес. до 2 лет, для адаптации от 1 до 3 мес.
- **Целевая должность** — при указании руководитель сможет автоматически установить должность после завершения
- **Целевая позиция** — при запуске по карьерной траектории поле заблокировано
- **Следующая программа** — для автоматизации последовательности программ

### Выбор компетенций и уровни владения
- **Серая галочка** — сотрудник не владеет; обязательно для освоения (нельзя убрать)
- **Синяя галочка** — сотрудник владеет; выбрано, но можно убрать
- **Академическая шапочка** — сотрудник эксперт; не выбрано, но можно добавить

### Сроки и развивающие действия
- Для каждой компетенции можно указать дату дедлайна
- Кнопка «Действий N/M» — слайдер выбора развивающих действий для компетенции
- Кнопка «Добавить» — добавление других видов развивающих действий (только уже созданные)

### Лимит на количество программ
- По умолчанию: не более 2 программ одновременно в работе
- В настройках модуля можно увеличить до 5
- При превышении лимита кнопка запуска блокируется

## Предусловия

- Права на запуск программ развития
- Созданные шаблоны (для запуска по шаблону)
- Привязка сотрудника к позиции (для запуска по карьерной траектории)

## Ожидаемый результат

После запуска в профиле сотрудника появляется карточка развития, готовая к прохождению.

## Граничные случаи

- Если лимит превышен — кнопка запуска заблокирована
- Компетенции с серой галочкой нельзя убрать
- Компетенции с академической шапочкой не выбраны, но можно добавить
- Без выбора компетенций запуск невозможен
