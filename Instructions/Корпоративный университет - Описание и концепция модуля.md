# Корпоративный университет - Описание и концепция модуля

**Модуль:** [[Module - Корпоративный университет]]

## Описание

Корпоративный университет (КУ) — инструмент для обучения сотрудников компании. С помощью модуля сотрудники осваивают и развивают профессиональные компетенции (hard и soft skills) без отрыва от производства. Для обучения используются программы развития (ИПР) — планы развивающих действий.

## Ключевые функции

### Концепция модуля
- **Адаптация** — эффективное прохождение испытательного срока через программы адаптации
- **Развитие** — повышение квалификации через программы развития
- **Адаптация + Развитие** — одновременная адаптация и оттачивание знаний до уровня должностных обязанностей

### Шесть типов развивающих действий
1. **Курсы и тесты** — собственные обучающие курсы с тестами для проверки остаточных знаний
2. **Книги** — электронный каталог книг через модуль «Библиотека» (интеграция с МИФ, Альпина)
3. **Мероприятия** — тренинги, лекции, воркшопы, планируемые HR-специалистом
4. **Наставник** — эксперты помогают коллегам в освоении компетенций; можно запланировать встречу через карточку развития
5. **Задачи и проекты** — применение знаний на практике; задачи автоматически ставятся в Битрикс24
6. **Развитие на рабочем месте** — справочник любых развивающих действий (внешние сайты, онлайн-лекции и т.п.), пополняемый всеми сотрудниками

### Уровни владения компетенциями
- **Серая галочка** — сотрудник не владеет компетенцией
- **Синяя галочка** — сотрудник владеет компетенцией на достаточном уровне для работы
- **Академическая шапочка** — сотрудник владеет компетенцией на экспертном уровне (может быть наставником)

### Позиции и определение пробелов в навыках (Skills Gap Analysis)
- За сотрудником может быть закреплена позиция с набором требуемых компетенций
- При запуске развития на основе карьерной траектории модуль автоматически определяет компетенции, которые сотрудник ещё не освоил, и добавляет их в карточку развития
- Если к компетенциям прикреплены развивающие действия, они также добавляются автоматически

### Три варианта запуска развития
1. **Запуск по карьерной траектории** — развитие в позицию (вышестоящую или смежную), автоматическое определение компетенций из профиля позиции
2. **Запуск по шаблону** — заранее подготовленный набор компетенций (например, «Адаптация нового сотрудника»)
3. **Свободный выбор компетенций** — ручной выбор компетенций для целенаправленной отработки

### Контроль за развитием
- HR-специалисты и руководители следят за прогрессом в разделе «Мониторинг развития»
- HR видят карточки всех сотрудников, руководители — свои и подчинённых

### Интеграция с Оценкой 360
При установленном модуле «Оценка 360» уровень владения компетенцией определяется числовым значением по шкале (например, от 1 до 10), что позволяет глубже анализировать пробелы в навыках с учётом оценок по отдельным индикаторам.

## Предусловия

- Установленный модуль «Корпоративный университет»
- Настроенные карьерные траектории (опционально)
- Заполненная система компетенций
