# Корпоративный университет - Типы программ

**Модуль:** [[Module - Корпоративный университет]]

## Описание

Для обучения в Корпоративном университете используются программы развития (ИПР). Каждая программа — это список компетенций с набором развивающих действий, которые сотрудник должен выполнить для освоения компетенции.

## Ключевые функции

### Программа развития
- Набор компетенций (soft и hard skills, корпоративные компетенции)
- Имеет руководителя, чёткие сроки, список развивающих действий
- Сроки по умолчанию: от 6 месяцев до 2 лет (настраивается в административной части)

### Цели программ развития
- Развитие для перехода на вышестоящую или смежную позицию
- Развитие в рамках текущей позиции
- Изучение отдельных компетенций по желанию сотрудника или для кадрового резерва
- Выполнение отдельных развивающих действий в целях саморазвития

### Три варианта запуска
1. Запуск по шаблону
2. Запуск на основании карьерной траектории или текущей позиции
3. Свободный выбор компетенций

### Программа адаптации
- Та же программа развития, но нацеленная на онбординг новых сотрудников
- Сроки по умолчанию: от 1 до 3 месяцев (настраивается)
- Единственный вариант запуска — по шаблону

### Включение/отключение программ адаптации
- По умолчанию в настройках модуля включена опция «Использовать программы адаптации»
- При отключении опции создание шаблонов и запуск программ адаптации становятся недоступны

### Автоматический запуск программ адаптации
- При создании шаблона можно включить опцию автоматического запуска
- При добавлении новых сотрудников программа адаптации запускается автоматически по преднастроенному шаблону
- Для разных подразделений можно создать свои шаблоны

## Предусловия

- Настроенные компетенции и развивающие действия
- Созданные шаблоны программ (для запуска по шаблону)
