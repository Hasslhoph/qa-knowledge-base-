# Создание и редактирование опроса

**Модуль:** [[Module - Опросы]]

## Описание

Инструкция по созданию, редактированию и удалению опросов. Доступно только администраторам и редакторам опросов.

## Ключевые функции

### Добавление опроса

1. Перейти на главную страницу модуля → кнопка «Настройки» (⚙️) → «Добавить опрос»
2. Заполнить слайдер создания опроса:

| Параметр | Описание |
|---|---|
| Название | Обязательно для заполнения |
| Описание | Цели опроса, информация для респондентов |
| Картинка | Обложка для опроса |
| Активность | Влияет на видимость в общем списке |
| Обязательный опрос | Для пульс-опросов — всплывающее окно на каждой странице |
| Дата начала / окончания | Срок сбора голосов |
| Группа | Категория опросов (обязательно) |
| Оповещать автора | Уведомления о новых голосах (мессенджер / e-mail) |
| Кол-во вопросов на странице | Постраничная навигация по вопросам |
| Разрешить менять мнение | Кнопка «Переголосовать» для респондентов |
| Сделать опрос анонимным | Скрыть результаты от обычных пользователей |
| Права доступа | Настройка по категориям: группы пользователей, пользователи, сотрудники и отделы, группы соцсети, другие роли |

### Права доступа к опросу

Настроить права можно для следующих категорий:

- **Группы пользователей** — настройки действуют для всех участников группы
- **Пользователи** — индивидуальные настройки для отдельных сотрудников
- **Сотрудники и отделы** — настройка с учётом оргструктуры компании
- **Группы социальной сети** — участники групп/проектов корпоративного портала
- **Другие роли** — например, все авторизованные пользователи, авторы контента

Права доступа:

- **Закрыт** — опрос не отображается в общем списке. Доступ остаётся у администраторов и редакторов опросов
- **Смотреть результаты** — только просмотр результатов без голосования. Если включена анонимность, кнопка «Результаты» также не отображается
- **Принять участие** — доступ к голосованию

### Дополнительные функции (при наличии хотя бы одного вопроса)

- **Предпросмотр** — открывается новая вкладка, где показано, как будет выглядеть опрос после публикации
- **Результаты** (доступно при наличии хотя бы одного голоса):
  - **Смотреть диаграмму** — страница с графиками и диаграммами результатов
  - **Смотреть таблицу** — слайдер с результатами в виде таблицы (кто проголосовал и какие варианты выбрал)
  - **Обнулить** — очищает результаты опроса, пользователи могут пройти его заново
  - **Excel с группировкой по ответам** — выгрузка с группировкой по ответам
  - **Excel без группировки** — выгрузка с детальной информацией о пользователях, ответах и дате голосования
- **Копировать** — создаётся копия опроса с идентичными настройками и вопросами
- **Удалить** — удаление опроса (все вопросы и ответы будут стёрты)

### Описание для респондентов и резюме

Кнопка «Описание для респондентов и резюме» появляется в верхней части слайдера после того, как опрос сохранён. При нажатии открывается меню действий:

- **Описание для респондентов** — открывается слайдер со стандартным визуальным редактором Битрикс24. Можно добавить сопроводительный текст, изображения и файлы, которые будут отображаться на странице голосования. Когда описание добавлено, в меню действий появляется синяя галочка
- **Описание для резюме** — форма для добавления резюме, которое сотрудники увидят после прохождения опроса на странице результатов. Если опрос анонимный, страница результатов недоступна обычным пользователям. В резюме можно добавить текст и прикрепить файлы. Предусмотрена настройка доступа к резюме. Как правило, резюме составляется по завершении опроса и содержит краткий вывод о проведённом исследовании

### Причины, по которым опрос не отображается

Бывают случаи, когда опрос не появляется в общем списке после сохранения. Возможные причины:

1. **Отключена галочка «Активность»** — обычные пользователи не увидят опрос в общем списке. Администратору или редактору нужно перейти в «Управление опросами», убедиться что в колонке «Активность» стоит «Да», и при необходимости включить активность в режиме редактирования
2. **Дата начала опроса ещё не наступила** — опрос находится в списке «Неактивные», который виден только администраторам и редакторам. Чтобы изменить дату, нужно отредактировать опрос через меню управления
3. **Группа опроса скрыта в настройках модуля** — в административной части портала (Настройки → Настройки продукта → Настройки модулей → Улей: Опросы) нужно проверить блок «Отображаемые группы опросов» и убедиться, что нужная группа отмечена серым цветом
4. **Включена опция «Разрешить только один текущий опрос в группе»** — в этом случае в группе отображается только один действующий опрос. Изменить настройку можно в административной части портала: Сервисы → Опросы → Группы опросов, на вкладке «Свойства» снять соответствующую галочку

## Предусловия

- Пользователь — администратор или редактор опросов
- Модуль установлен и активен

## Шаги

1. Перейти на главную страницу модуля «Опросы»
2. Нажать «Настройки» (⚙️) → «Добавить опрос»
3. Заполнить обязательные поля: Название, Группа
4. Настроить дополнительные параметры по необходимости
5. Сохранить опрос
6. Добавить вопросы через [[Опросы - Добавление вопросов и ответов]]

## Ожидаемый результат

Новый опрос появляется в общем списке и доступен для голосования целевой аудитории.

## Граничные случаи

- При удалении опроса все его вопросы и варианты ответов также стираются
- Переголосования не учитываются как новые голоса — голос пользователя учитывается только один раз
- В анонимных опросах обычные пользователи не видят количество голосов и страницу результатов
- Привилегированные пользователи видят результаты анонимных опросов в обезличенном виде

## Баллы Геймификации за прохождение опросов

Если на портале установлен модуль «Улей: Геймификация», за голосование в опросах сотрудники могут получать внутреннюю валюту (баллы). Накопленные баллы можно потратить в [[Геймификация - Магазин бонусов]].

Модули позволяют настроить начисление баллов как для целой группы опросов, так и для каждого опроса индивидуально. Сумма баллов для групп опросов указывается в настройках Геймификации.

На слайдере создания/редактирования опроса есть иконка Геймификации. Число рядом с иконкой показывает, сколько баллов будут получать сотрудники за прохождение опроса. При клике на иконку открывается слайдер с настройками:

1. **Группа опросов** — заблокированное поле с названием группы
2. **Кол-во начисляемых баллов** — заблокированное поле с суммой баллов из настроек группы
3. **Установить индивидуальное количество баллов для данного опроса** — можно указать свою сумму. Индивидуальная настройка перебивает настройку группы. `0` = не начислять баллы за данный опрос. Пустое поле = начислять исходя из настроек группы

Увидеть начисления за прохождение опросов сотрудники могут в разделе «Операции» модуля «Геймификация».
