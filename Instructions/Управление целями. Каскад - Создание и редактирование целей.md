# Создание и редактирование целей

**Модуль:** [[Module - Управление целями. Каскад]]

## Описание

Инструкция по созданию типов целей, массовой настройке доступа к целям, добавлению, редактированию и удалению целей в каталоге модуля.

## Ключевые функции

> Управление каталогом корпоративных целей.

- Создание типов целей в публичной части модуля
- Массовая настройка доступа к целям
- Добавление целей с настройками: активность, тип, вес, каскадирование, цвет, права
- Редактирование и удаление целей
- Ограничения при использовании целей в запущенных процессах

## Создание типов целей

Добавлять, изменять и удалять типы целей могут только администраторы модуля. Перейдите в раздел «Каталог целей» и нажмите на шестеренку > «Типы целей».

В результате откроется слайдер со списком всех типов целей. Создайте нужное количество типов целей и дайте им название. Нажмите «Сохранить», когда закончите работу с целями.

В любой момент вы можете менять типы целей местами. Для этого зажмите нужную строку и передвиньте ее выше или ниже.

Для удаления типа цели нажмите на бургер-меню слева от нее. Если в тип уже добавлены какие-то цели, бургер-меню не появится и удалить тип цели будет нельзя.

После этого добавленные вами типы можно будет выбрать при создании целей и при добавлении их в карточку целей.

## Доступ к целям

При необходимости модуль позволяет массово настраивать доступ к целям. По умолчанию все цели создаются недоступными для сотрудников и видеть их может только администратор. Если цель недоступна, то пользователь не увидит такую цель в списке при заполнении карточки цели. Благодаря этому доступ к целям можно разграничивать например по отделам, чтобы при заполнении карточек руководители и их подчиненные видели только предназначенные для них цели.

Чтобы закрыть/открыть доступ ко всем целям перейдите в раздел «Каталог целей» и нажмите на шестеренку > «Доступы».

Откроется слайдер с текущими настройками доступа. Чтобы открыть всем сотрудникам доступ к целям, для группы «Все посетители» установите тип доступа «Чтение». Сохраните изменения.

Теперь все существующие и новые цели будут доступны всем сотрудникам при заполнении карточек. Менять права доступа в настройках каждой конкретной цели не потребуется.

Чтобы закрыть доступ к целям для всех сотрудников, установите группе «Все посетители» тип доступа «Нет доступа». В результате сотрудники не будут видеть цели при заполнении своих карточек и доступ к каждой цели нужно будет настраивать отдельно при создании/редактировании данной цели.

## Добавление целей

Доступ только администраторам модуля. Раздел «Каталог целей» → «Добавить цель».

### Параметры цели

1. **Активность цели.** Влияет на добавление цели в карточку целей. Если галочка активна, сотрудники будут видеть данную цель в выпадающем списке и смогут добавить ее в свою карточку. Если галочка убрана, цель нельзя будет добавить в карточку. Доступ к цели будет только у администратора и сотрудника внутреннего контроля в разделе «Каталог целей».

2. **Название цели.** Обязательное поле.

3. **Тип цели.** Категория цели (стратегические, маркетинговые и т.д.).

4. **Минимальный вес цели.** Минимальный вес одной цели, который пользователь может указать в карточке цели. Вес — это приоритетность цели, чем больше вес, тем приоритетнее цель. По умолчанию 10. Суммарный вес всех целей в одной карточке должен быть равен 100.

5. **Шаг изменения веса цели.** Шаг для указания веса. Например, если шаг равен 5, то сотрудник может указать вес 15, 20, 25 и так далее.

6. **Максимальный % выполнения цели.** Максимальный процент выполнения цели. Например, 120% для учета перевыполнения плана.

7. **Шаг изменения % выполнения цели.** Шаг для указания прогресса. Например, если шаг равен 5, то прогресс можно указать 5%, 10%, 15% и так далее.

8. **Текст подсказки при редактировании веса цели.** Пояснение для сотрудников о том, как правильно указывать вес цели. Отображается как всплывающая подсказка.

9. **Текст подсказки при редактировании % выполнения цели.** Пояснение для сотрудников о том, как правильно фиксировать прогресс по цели. Отображается как всплывающая подсказка.

10. **Возможности каскадирования.** Вкл/выкл автоматическое каскадирование цели подчиненным. Если опция отключена, руководитель по-прежнему сможет вручную добавлять цели в карточки подчиненных. Если опция включена, первыми свои карточки целей должны заполнить руководители — пока их цели не утверждены, подчиненные не смогут приступить к заполнению собственных карточек.

11. **Фоновый цвет.** Позволяет задать фоновый цвет для каждой цели. Цвет отобразится в карточках целей и оценок.

12. **Настройка прав.** Настройка прав доступа к цели. По умолчанию цель скрыта ото всех пользователей, кроме администраторов модуля и сотрудников внутреннего контроля. Чтобы другие сотрудники видели цель и могли добавить ее себе в карточку, выберите группу пользователей и укажите для нее права «Чтение».

## Редактирование и удаление целей

- **Редактирование:** бургер-меню (≡) → «Изменить»
- **Удаление:** бургер-меню (≡) → «Удалить»

### Важные ограничения

- Если цель используется в запущенном процессе — тип и название редактировать нельзя
- Отключение активности не скрывает цель из уже добавленных карточек
- Если цель используется в запущенном процессе, она исчезнет из карточек целей, карточек оценок и из сводного отчета — удалять используемые цели не рекомендуется

## Предусловия

- Роль администратора модуля (для создания типов целей и добавления целей)

## Граничные случаи

- Суммарный вес всех целей в одной карточке должен быть равен 100
- Минимальный вес нужен для реалистичной расстановки приоритетов
- При включенном каскадировании руководители заполняют карточки первыми
- Если в тип уже добавлены цели, удалить тип цели нельзя
