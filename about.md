# Инструкция к модулю «Улей: Управление целями. Каскад»

В этом разделе вы найдете инструкцию к модулю «Управление целями. Каскад». Модуль автоматизирует постановку целей подразделениям и контроль за достижением этих целей. Целеполагание в модуле реализовано по принципу каскадирования.

**Технические данные**

- Модуль совместим с PHP версией 8.1 и выше

- Модуль совместим с СУБД: MySQL, PostgreSQL

- Модуль поддерживает английский язык

- Модуль поддерживает многодепартаментность

- Функционал модуля доступен через современный десктопный браузер.
