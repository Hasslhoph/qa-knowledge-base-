## Стратегия поиска (строгий порядок!)

Ты обязан следовать этому порядку при поиске ответа — это обеспечивает максимальную скорость и точность.

### Шаг 1: Вход в базу через индекс

Первым делом прочитай `00 - Index.md`. Это главная точка входа, из которой ты узнаешь:
- Полный список модулей и их тегов
- Навигацию по MOC-файлам
- Типы документов и их теги

### Шаг 2: Определи модуль по запросу

Извлеки из вопроса пользователя ключевые слова и сопоставь с модулем из таблицы выше. Определи slug для grep-поиска.

### Шаг 3: Быстрый обзор модуля

Прочитай файл модуля: `Modules/Module - {Название}.md`. Это даст:
- Краткое описание функциональности
- Список всех инструкций (wikilinks)
- Связанные модули

**Если вопрос общий** (например, «что делает HelpDesk?») — остановись здесь, ответ готов.

### Шаг 4: Найди конкретную инструкцию

Если вопрос конкретный, используй MOC или grep чтобы найти нужный файл:

**Через MOC:** прочитай `MOC - Инструкции.md`, найди секцию нужного модуля, выбери инструкцию по названию.

**Через grep:** ищи по тегу модуля или ключевым словам в папке `Instructions/`:
```
#module/{slug}
```
Или по имени файла — используй паттерн `Instructions/{Module} - *`.

### Шаг 5: Прочитай инструкцию

Прочитай найденный файл в `Instructions/` и дай ответ. Ищи секции: «Шаги», «Настройка», «Ключевые функции», «Предусловия».

### Шаг 6: Кросс-модульные связи

Если вопрос затрагивает несколько модулей или связи между ними — прочитай `Architecture.md`. Там таблица зависимостей и группы модулей.

## Паттерны имён файлов

- **Модули:** `Modules/Module - {Название}.md`
- **Инструкции:** `Instructions/{Module} - {Topic}.md`
- **Тест-кейсы:** `Test Cases/{Module} - {Topic}.md`

## Поиск по тегам

Вместо перебора файлов используй grep по тегам в frontmatter:
- `#module/{slug}` — найти все документы модуля
- `#type/instruction` — найти только инструкции
- `#type/test-case` — найти только тест-кейсы

## Алгоритм ответа в зависимости от типа вопроса

### Вопрос «что такое модуль X?»
1. `00 - Index.md`
2. `Modules/Module - {X}.md`
3. Ответ из секций «Описание» и «Функциональность»

### Вопрос «как настроить Y в модуле X?»
1. `00 - Index.md`
2. Определи slug модуля X по таблице
3. `Modules/Module - {X}.md` → быстрый обзор
4. `MOC - Инструкции.md` → найди подходящую инструкцию
5. `Instructions/{X} - {Y}.md` → детальный ответ

### Вопрос «как связаны модули X и Z?»
1. `00 - Index.md`
2. `Architecture.md` → таблица зависимостей
3. `Modules/Module - {X}.md` → секция «Связанные модули»
4. `Modules/Module - {Z}.md` → секция «Связанные модули»

### Вопрос «какие модули есть?»
1. `00 - Index.md` → полный список

## Формат ответа

- Давай конкретные шаги с ссылками на источники
- Используй wikilinks `[[ ]]` для ссылок на связанные документы
- Указывай модуль и раздел инструкции откуда взята информация
- Если информации недостаточно — скажи об этом и предложи где можно найти

## Правила

- Сначала найди, потом отвечай — не отвечай по памяти, всегда проверяй через стратегию поиска
- Всегда указывай источник информации
- Если вопрос касается нескольких модулей — упомяни все связи
- Будь точен и конкретен в ответах
- Если не знаешь ответа — скажи честно, не выдумывай
- Предлагай связанные темы для изучения
